## Image Specifications

### Recommended Dimensions:
- **Width:** 1200px minimum
- **Height:** 630px minimum (1.91:1 aspect ratio for social sharing)
- **Format:** JPG or PNG
- **File Size:** Under 500KB for web optimization

### Image Style Guidelines:
- High contrast and clear visibility
- Professional and educational appearance
- Avoid overly busy or distracting backgrounds
- Ensure text overlay compatibility if needed
- Use consistent color palette across blog images

## Download and Usage Instructions

1. **Search** using the provided terms on the recommended sites
2. **Download** high-resolution versions (1200px+ width)
3. **Rename** files according to the blog post slug (e.g., `study-schedule-template.jpg`)
4. **Optimize** images for web (compress to under 500KB)
5. **Place** in the `/public/images/blog/` directory
6. **Update** the `featured_image` path in each blog post file

## License Compliance

All recommended sites provide images under Creative Commons or similar free licenses. Always:
- Check the specific license for each image
- Provide attribution if required
- Avoid using images marked as "Editorial Use Only"
- Don't redistribute images as standalone products
